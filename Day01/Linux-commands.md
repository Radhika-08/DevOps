# Linux Commands Notes

## pwd

Displays the current working directory.

Example:

```bash
pwd
```

----

## ls

Lists files and folders in the current directory.

Example:

```bash
ls
```

----

## cd

Changes the current directory.

Example:

```bash
cd testfolder
```

----

## whoami

Displays the current logged-in user.

Example:

```bash
whoami
```

----

## id

Displays user and group information.

Example:

```bash
id
```

----

## date

Displays current date and time.

Example:

```bash
date
```

----

## mkdir

Creates a new directory.

Example:

```bash
mkdir testfolder
```

----

## touch

Creates a new file.

Example:

```bash
touch file1.txt
```

----

## echo

Displays text or writes text into a file.

Example:

```bash
echo "Hello DevOps"
```

Write text into a file:

```bash
echo "Hello DevOps" > file1.txt
```

----

## grep

Searches for specific text inside a file.

Example:

```bash
grep "Linux" notes.txt
```

----

## head

Displays the first lines of a file.

Example:

```bash
head notes.txt
```

Display first 2 lines:

```bash
head -n 2 notes.txt
```

----

## tail

Displays the last lines of a file.

Example:

```bash
tail notes.txt
```

Display last 2 lines:

```bash
tail -n 2 notes.txt
```

----

## cp

Copies a file.

Example:

```bash
cp file1.txt copyfile.txt
```

----

## mv

Moves or renames a file.

Example:

```bash
mv file2.txt renamed.txt
```

----

## rm

Deletes a file.

Example:

```bash
rm copyfile.txt
```

----

## cat

Displays file content.

Example:

```bash
cat file1.txt
```

----

## chmod

Changes file permissions.

Example:

```bash
chmod 777 file1.txt
```

----

## find

Searches for files and folders.

Example:

```bash
find . -name "*.txt"
```

----

## history

Displays previously executed commands.

Example:

```bash
history
```

----

## clear

Clears the terminal screen.

Example:

```bash
clear
```
